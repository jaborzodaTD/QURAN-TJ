# QURAN TJ — Қуръони Карим бо тарҷумаи тоҷикӣ

**JABORZODA FAYZALI**

A mobile-first Android Quran reader with a premium Islamic visual design.

## Content integrity

This project deliberately does **not** invent, rewrite, paraphrase, or manually type Quran verses.

- **Arabic Quran text:** Tanzil Project, Uthmani text v1.1. The Tanzil license permits verbatim use in an application with attribution and requires that the Quran text not be changed.
- **Tajik meanings translation:** QuranEnc.com — Tajik translation by Rowwad Translation Center, translation key `tajik_arifi`. QuranEnc's republication terms require the translation to be kept unchanged, with source/publisher attribution and version information.

The app retrieves each surah from the cited source and caches the exact response locally after a successful load.

## App

- 114 surahs
- Arabic text above Tajik translation for every ayah
- Surah search
- Dark mode
- Reading font-size control
- Local cache for previously opened surahs
- Source and license attribution inside the reader
- Premium Islamic/emerald/gold visual language
- GitHub Actions debug APK build

## Important

A Quran translation is a translation of meanings and is not the Quran itself. The Arabic text remains the primary Quranic text.
